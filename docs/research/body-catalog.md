# 身体动作与空间行为目录的参考与边界

核对日期：2026-09-21。

## 参考范围

查阅 [NTU ROSE Lab 的动作识别项目页](https://rose1.ntu.edu.sg/dataset/actionRecognition/) 与 [作者维护的 NTU RGB+D 官方仓库](https://github.com/shahroudy/NTURGB-D)。项目按日常活动、人际互动等类别组织动作，并通过身体关节表示运动。这里采用的是“把动作按运动任务、交互对象和实际涉及部位拆开检查”的组织方法，未下载视频、骨架或训练样本，也未搬运类别说明作为中文句库。

本目录的中文描写、行为意义、适用事实与状态约束均为本项目逐条原创。参考来源提供覆盖检查思路，不提供情绪诊断依据。某个手势与多种情绪关联，不意味着可以据此判断现实人物的心理。

## 落位内容

- `data/catalog/body.json`：300 条独立记录，涵盖头颈、躯干、平衡、手势、日常衣饰、自我照料、持物检查、精细工具操作、人际触碰及工作表面接触。
- `data/catalog/spatial.json`：107 条独立记录，涵盖许可与私密边界、座位投入程度、群体站位、视线共享、声学遮蔽、共享光热、地形净空、工作与危险区、照护通路及会合等待。

没有使用左右翻转、强度排列、器物名替换或笛卡尔积扩充数量。同一类任务共享语义家族，供跨回合反重复使用。身体目录的情绪关联覆盖 60 个已登记标签，空间目录覆盖 39 个；覆盖不等于声称所有情绪都有专属动作。

## 空间与物品约束

道具使用必须有事实支持，持物动作还必须通过实际手部占用与对象标签核验。`held.both.*` 表示双手正在共同握同一对象，不能由两个无关物件冒充。衣物、泪水、汗液、笑声、伤处、对方主动伸手等前态都要由输入事实提供。互动触碰须声明接触部位可达；描写不替对方做出移动或接受接触的决定。

空间目录不绕过导航。两条永久朝向改变使用正式 `orientation` 效果。其余条目要么维持事实明确的现有空间关系，要么只做原地探头、屈身、调整重心等短暂动作并恢复。候见线、伞下、队尾、桥心等地点必须已经到达，不能由选择描写条目自动到达。静态站位描述用于表现人物如何使用当前环境，不替代寻路与距离状态转换。

## 本地验证

两份 JSON 均通过解析、`CatalogRecord` 校验和 `compile_record` 情绪解析。300 / 107 条的 ID 与完整中文句子分别全部唯一；各文件内两两句子比较，`difflib.SequenceMatcher` 相似度不低于 0.77 的句对为零。该指标只检查文字近重复，不替代行为语义审查；共享语义家族与运行时反重复仍是必要条件。

正文已去掉把数据约束直接说给读者的实现痕迹；工程前提留在 `facts` 与 `meaning`。看、听、说等附带任务声明相应能力；左右手及涉及的身体部位用于伤势过滤。全包构建、场景见证和回归测试由主任务统一执行。
