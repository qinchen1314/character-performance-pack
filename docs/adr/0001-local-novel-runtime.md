# ADR 0001 — 优先交付本地中文小说运行链

日期：2026-09-21。状态：已实施的工程选择；完整 v1.0 尚未验收。

用户确认用途为小说角色情绪与动作。现有仓库只有 Phase 0–2 基础，且有尚未实现的用户验收测试。本次优先补齐输入、规划、中文表达和连续写作，使其能被小说 Agent 直接调用。

1. **运行形态**：Python 包 + CLI；SQLite 负责场景 revision、角色快照、临时计划、渲染结果与历史。REST 服务可选，未引入。
2. **状态权威**：本地存储为已提交场景/世界状态的权威；上游负责输入情绪、关系和身体状态。上游不能通过下一回合请求直接覆盖已提交的位置或资源。外部世界同步另需显式接口。
3. **安全降级**：参考 Composer 每回合至多一个会改变物理状态的动作，不自动推测导航和座位。缺失必要事实会在 suppressed_candidates 中记录前置条件，缺少情绪输入则产生 STATE_INCOMPLETE 空计划。
4. **渲染边界**：独立检查器验证每个 fragment 是否属于允许表达以及全文拼接是否一致。LLM 只选择允许选项；自由生成正文和调用真实供应商不是本切片的完成条件。台词与显示人名是调用方提供的可引用文本，原样保留。
5. **原创数据**：新增 58 单元、六条 Modifier 与语法完全原创，VAD 为工程先验、不是心理学实测数据；原有情绪来源记录保持不变。没有下载受限材料，也没有重新宣布第三方数据可商用。
6. **规则配置**：评分权重通过 `ScoringRules` 注入；Modifier DSL 固定人格→关系→场景→身体→导演→世界顺序。分数贡献使用独立 namespace，防止覆盖硬约束或重复惩罚；参数逐项截断。
7. **版本与恢复**：Pack 0.2.0 / schema 1.0.0 / rule 1.0.0。计划绑定内容哈希与完整输入及历史快照；更换 Pack 后旧计划不可直接重新验证/提交。SQLite 初始化自动补充渲染结果列，迁移持有写锁。
8. **现实边界**：当前只提供 general/xianxia 两个类型，四级原创境界；能力范围必须经 pack 配置与用户世界观校准。尚未实现动作 duration/completion 状态机、通用过渡搜索、服务访问控制与保留期策略、Pack 热切换签名和大规模数据扩展。

这些决策使本地切片可用，并不改变实现文档对完整生产版的退出条件。
