# 0.5.0 — 真人盲评闭环与首轮编辑清理

## 功能边界

本轮完成的是可执行、可复现的真人盲评闭环，不虚构真人评审结果。`cpp-blind-review prepare` 将目录身份与公开评审包分离；同一有效条目默认放进三个不同题材、文风和角色壳，最后打乱顺序。内置壳覆盖武侠、都市情感、刑侦、校园成长、古言、科幻与仙侠。

`cpp-blind-review aggregate` 按稳定评审者 ID 汇总。每名真人无论评价多少角色壳，对同一条目的权重都相同；同一评审者不能重复计成人数。至少两名独立评审者后才产生 keep/rewrite/remove，未达门槛保持 pending。

## 编辑预清理

在真人评分尚未收集前，先停用 21 条明显具有操作说明感、机械复位措辞、抽象指代或正文价值过低的记录。它们没有从作者目录或 Pack 物理删除，而是保留 `editorial_status: rejected`、逐条理由与 `replacement_id`；编译后状态为 `deprecated`，供旧计划兼容，新规划与盲评包会排除。

生产 Pack 仍保留 1024 条兼容记录，其中 1003 条活跃、21 条废弃。活跃目录的十类覆盖门槛仍全部通过：微表情 101、面部与视线 158、身体 307、空间 112、生理 105、言语 108、修仙 108；66 种情绪仍各有至少三个活跃候选和两个通道。逐条清理依据见 [编辑预清理报告](../evaluation/editorial-preclean.md)。

## 验证与诚实声明

单元与集成测试覆盖匿名隔离、多壳覆盖、独立评审门禁、评审者等权汇总和拒绝条目不可编译。全量测试 153 项通过；清理后的编译、目录数量、重复与情绪覆盖门禁通过。

截至本报告生成时，尚未收到两名或以上外部真人评审者的评分文件，因此不报告“真人通过率”“偏好胜率”或角色识别率。编辑预清理不能替代真人盲评；后续真人结果必须通过答案映射和汇总器产生。
